# Origen de esta carpeta

Copia de la versión **v1.0.0** del repo `dismascapacidad/dismascapacidad-design`
(archivos `css/fonts.css`, `css/tokens.css` y `css/fonts/`).

**No editar a mano.** Para cambiar colores o tipografía, se cambia en el repo de
diseño, se publica una versión nueva y se vuelve a copiar acá.

`theme.css` (roles claro/oscuro) no se copia porque este sitio no tiene modo oscuro.
